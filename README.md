# Little Web Apps

A growing portfolio of small web apps and experiments. Each project lives in its own folder so new ideas can be added without mixing their files.

## Projects

- [Castellion](castellion/index.html) — a mobile-first solo prototype inspired by the School of Architects introductory rules.

## Run locally

Open `index.html` in a browser, or serve this folder with Python:

```powershell
py -m http.server 8000
```

Then open `http://localhost:8000` on the computer. For phone testing, start the server with `--bind 0.0.0.0` and open the computer's local IP address on the same Wi-Fi.

## Add another app

Create a folder for the app at the repository root and add a project card to `index.html`. Keep each app's assets and instructions inside its folder.

## GitHub Pages

The site is static and can be hosted from the repository root using GitHub Pages. The project links are relative, so Castellion works from the root portfolio URL.
