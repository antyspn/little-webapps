# Castellion: The Architect's Trial

An unofficial solo browser prototype for the School of Architects introductory level.

## Play

Open `index.html` in a modern browser. It works as a local static page and needs no install or build step.

## Current prototype

- Mobile-first layout keeps the castle and turn controls together on a phone screen.
- Tap a pile, then tap a glowing legal space to place a Defender; discard is an optional single tap.
- Inspect the discard pile, turn log, and supplied component photos in dialogs.
- Core placement rules, foundations, formations, traitor thresholds, Exam I requirements, and Exam II foundation destruction.
- Exam III randomly selects one of the three pictured formation cards: 3 towers + 2 bastions, 3 lines + 2 towers, or 3 bastions + 2 lines.
- Traitor counters clear only after a successful exam. A failed exam ends the trial and leaves its final counter visible.

The original photos are available from the Components button. Board tiles still use simplified CSS shapes and faction colors; accurate tile sprites can be added in a later pass. The base and expert levels, Defender powers, and two-player rules are not included yet.
